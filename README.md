This repository contains a collection of standalone solo projects that I built while learning **JavaScript**.

The goal of this repository is to track my personal growth, apply core theoretical concepts in practice (DOM manipulation, Async/Await, working with APIs, Event Handling, etc.), and build a solid foundation for web development.

- **Language:** JavaScript (ES6+)

- **Markup & Styling:** HTML, CSS

- **Development Environment:** VS Code, Git / GitHub, WSL
